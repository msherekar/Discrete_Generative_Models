# Verified Lecture 6 examples

These are actual outputs from seeded CPU runs on 2026-09-13. All 16 default
methods completed 1,000 training steps, sampled, and reproduced identical
seeded samples after checkpoint reload. Teacher/autoencoder stages also used
1,000 steps where applicable. The complete suite passed on PyTorch 2.9.1+cpu
and PyTorch 2.14.0+cpu with Python 3.12.14. These checked-in outputs use 2.9.1.
All 23 independent mathematical tests passed in both environments.

Reproduce the default runs from `lecture_6/`:

```bash
python run_all.py --out outputs/verified-torch291 --train-steps 1000
python -m unittest discover -s tests -v
python numerical_examples.py --output outputs/numerical
```

The fixed-length text examples recover almost all phrases in the four-family
grammar at eight steps. The expanding example still produces invalid
combinations; its support fraction is retained. Posterior means and variances
both have measurable error. Continuous samples cover the modes but retain
finite distributional error. These observations describe the actual small runs,
and are not evidence of reproducing paper-scale quality.

## Additional verified recipes

```bash
python examples/meta.py --finetune-steps 300 --out outputs/meta-finetune-verified
python run.py --mode sample --out outputs/meta-finetune-verified
python examples/ssfm.py --ssfm-target paper --lr 0.0001 --train-steps 2000 --out outputs/ssfm-paper-stable
python run.py --mode sample --out outputs/ssfm-paper-stable
```

`meta-finetune/` records the complete optional reward-drift stage and its
sampling metrics. `ssfm-paper/` records the paper's gradient orientation with
its separate lower-learning-rate recipe. Both reproduced seeded samples after
reloading. The paper-orientation recipe is optimization-sensitive: an initial
1,000-step run at learning rate 0.001 diverged in accuracy despite finite
numbers. Its same-noise RMSE was 51.94. This is why the default implementation
uses the released code's EMA split target. The lower-learning-rate paper run
also remained inaccurate, with same-noise RMSE 3.85 and one-step RMSE 22.40.
It is retained as an optimization-sensitivity comparison, not a successful
strong-solution fit. These failures concern this small-model training recipe;
they do not establish a general failure of the paper's objective.

`numerical_checks.json` retains the lecture's scalar-flow, posterior-gradient,
probability-update, insertion-clock, and Brownian-composition checks. The scalar
map's one-step endpoint RMSE is 0.011255 after 6,000 steps.

The JSON files preserve each executed configuration and the full loss history.
`checkpoint.pt` files are regenerated by the commands and excluded from Git,
matching the prior lecture folders. `training_reload_log.txt` and
`mathematics_test_log.txt` record the completed verification.
